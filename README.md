# Tic Tac Toe Game

## About the Project
This is a simple two-player Tic Tac Toe game made in C++.
I created this project to practise basic programming concepts and understand how game logic works.

## Features
- Two-player game (X and O)
- 3 x 3 game board
- Player input from positions 1 to 9
- Checks invalid and already occupied positions
- Detects a winner
- Detects a draw
- Option to play again

## Concepts Used
- Variables and data types
- 2D arrays
- Loops
- If-else conditions
- Basic input and output

## How to Run
1. Open this folder in VS Code.
2. Open the terminal.
3. Compile the program:

   `g++ main.cpp -o game`

4. Run it on Windows:

   `.\game`

## Note
This project was made for learning and practising basic C++ programming.
